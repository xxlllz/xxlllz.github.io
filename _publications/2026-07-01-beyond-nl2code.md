This survey provides a structured overview of multimodal code intelligence, covering systems that generate, edit, refine, execute, or reason with code from visually grounded inputs and outputs. It organizes recent work across graphical user interfaces, scientific visualization, structured graphics, and frontier agentic frameworks, and highlights verification-centered directions for evidence-grounded executable systems.
